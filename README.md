# Password Manager

A simple **Password Manager built with Python** that allows users to store, view, and generate passwords directly from the terminal.

##  Features

-  Add and save passwords for different websites
-  View saved passwords
-  Generate random passwords
-  Store passwords in a local `password.txt` file
-  Simple command-line interface
-  Built completely with Python

##  Technologies Used

- Python
- `random` module
- `string` module
- File Handling
